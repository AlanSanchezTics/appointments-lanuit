# Working Specs

This directory is the working area for Spec Kit feature artifacts.

Use it for one change at a time, typically in the form `specs/<feature>/`.
The contents here are temporary planning artifacts, not the permanent product contract.

Before a change is considered complete, reconcile the relevant working spec back into `docs/specification.md` and the related architecture or feature docs.
