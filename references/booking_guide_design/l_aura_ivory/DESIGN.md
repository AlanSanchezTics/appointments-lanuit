# Design System Documentation

## Theme Overview

This document outlines the core visual theme for our product, derived from our design tokens.

### Color Palette

The design system utilizes a `light` color mode.

- **Primary Color**: `#e49f53` - Our main brand color, used for key actions and branding.
- **Secondary Color**: `#2d2926` - A supporting color for less prominent elements.
- **Tertiary Color**: `#f8f4f1` - An accent color for highlights and decorative elements.
- **Neutral Color**: `#FDFBF7` - The base color for backgrounds and surfaces.

### Typography

- **Headlines**: `Montserrat` - Chosen for its modern and legible appearance in headings.
- **Body Text**: `Montserrat` - Ensures consistent readability across all textual content.
- **Labels**: `Montserrat` - Applied to form labels and small interactive text for clarity.

### Shape & Spacing

- **Roundedness**: `2` - A moderate level of roundedness for UI elements, offering a balanced and friendly aesthetic.
- **Spacing**: `2` - Normal spacing between elements, providing a clear and organized layout.
